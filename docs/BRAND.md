# Brand — Identity, Naming & Trademark Clearance

*The naming section is deliberately the longest part of this document. The last brand died on a name conflict; this one gets cleared first and filed before a single package is printed.*

## 1. Positioning

**For people who care what their desk looks like.** Not a peripherals company, not an esports brand — a *design studio that happens to print on desk mats* (and, from Q4, blanket hoodies). Original artwork, small drops, named designs with stories. Premium-indie price band (£29–35): above the commodity war, below the £60+ premium players.

Voice: maker-honest, a little dry, zero hype-bro. The founder story (clothing brand → trademark death → rebuild) is part of the brand, told plainly.

## 2. Visual identity

Theme: **dusk** — the hours people actually sit at their setups. Works in both name finalists (Deskloom / Duskloom).

### Typography & marks
- Logotype: a geometric grotesque (e.g. **Space Grotesk** — SIL Open Font Licence, free commercial use) in Ink; lowercase wordmark.
- Body/UI: **Inter** (OFL).
- Monogram: initial letter in a rounded square, Dusk Indigo — works as favicon, tissue-seal sticker, and embroidery when the Q4 hoodie line arrives.
- Packaging: kraft tube, one-colour Ink print, Ember sticker seal (see PLAYBOOK §5).

Method (all checks run **13 July 2026**): general web search for existing use → Trademarkia aggregate trademark search (indexes USPTO + international filings) → domain DNS/HTTP probe. This is a **knock-out screen, not legal clearance** — see §4 for the mandatory follow-through.

|---|---|---|---|---|
| **Deskloom** | Clean — no brand found (only unrelated "Loom" marks in other classes) | **0 results** ([Trademarkia](https://www.trademarkia.com/search/trademarks?query=deskloom)) | `.com` parked (buyable), **`.co.uk` unregistered** | ✅ **PRIMARY** |

**Recommendation: Deskloom** — "desk + loom" reads instantly (printed textiles for desks), extends naturally to the Q4 textile line, and every check came back clean. Note: a "desk loom" is also a generic term for a small weaving loom, which slightly *helps* (the mark is suggestive, not invented, but clearly distinctive for mats/Class 27) — an attorney may flag minor descriptiveness risk in Class 24; **Duskloom** is the fallback if so, and is the stronger mark overall.

## 4. Clearance checklist — do in this order, before anything is printed

1. **Manual database passes (free, ~30 min):**
   - [UKIPO trade mark search](https://trademarks.ipo.gov.uk/ipo-tmtext) — exact + phonetic variants (deskloom / desk loom / dusk loom)
   - [EUIPO eSearch](https://euipo.europa.eu/eSearch/) and [TMview](https://www.tmdn.org/tmview/) — EU + international
   - [USPTO search](https://tmsearch.uspto.gov/) and [WIPO Global Brand Database](https://branddb.wipo.int/)
   - (These block automated tools — the aggregate results above are strong signals, but the official databases must be eyeballed by a human.)
2. **Companies House** [name check](https://find-and-update.company-information.service.gov.uk/) + register the `.co.uk` and (optionally) buy the parked `.com`; grab matching handles on TikTok, Instagram, Etsy.
3. **Classes to file:** **27** (mats/floor & surface coverings — the core product), **35** (retail services), and — because the Q4 line and heritage are textiles — **24** (textile goods) and **25** (clothing, for the blanket-hoodie line). UKIPO fee: **£170 first class + £50 per extra class** (~£320 for four) via [gov.uk](https://www.gov.uk/how-to-register-a-trade-mark).
4. **Optional but recommended given history:** a solicitor/attorney full-availability search (~£200–400) before filing.
5. **File the UK application, then start using the name** — protection runs from filing date; registration completes ~4–6 months if unopposed, which is also the gate for Amazon Brand Registry (see MARKETING §5).
6. EU filing (EUIPO, €850 one class) only when EU sales justify it — GB-only at launch anyway (compliance §7.3).
